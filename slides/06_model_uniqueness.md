# 危険度予測モデルの独自性

(モデルの仕組み・精度は4ページ目「予測するAI・説明するAI」参照)

## 独自性

1. 既製のAI APIに丸投げせず、データ収集・特徴量設計・ファインチューニング・評価プロトコルまで一気通貫で自前構築
2. AIの危険度“予測”と実データを重ねて比較でき、まだ事故が記録されていない場所の潜在リスクも補完
3. 判断根拠は信号・横断歩道・見通し(PLATEAU実測値)など現地で確認できる「事実」で示す
4. 事前登録方式・複数シードでの再現性確認・bootstrap法による統計的検証を伴う誠実な評価プロセス

## 学習データの規模

- 事故データ29,284件(2019〜2024年、約6年分)、学習3,803セル・評価896セルの地図画像(データ拡張で15,212枚まで拡張)、PLATEAU見通しデータ23区内1,917セル

## 誠実な検証の積み重ね

- 全域評価では数値が水増しされていたと自ら気づき、都市部限定でより正直な数値に下方修正した上で公式採用
- 特徴量計算バグを目視確認で自己発見・修正し、判定基準は結果を見る前に固定して運用
