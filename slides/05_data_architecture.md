# 活用データ・周辺アーキテクチャ

## 活用するオープンデータ

- 都内15区教育機関一覧(東京都オープンデータカタログサイト): 区立小中学校773校の位置を地図上に常時表示
- 警察庁 交通事故統計情報オープンデータ: 東京都内の歩行者事故、2019年〜2024年(約6年分)。危険度予測モデルの正解ラベルに使用
- 国土地理院 地理院タイル(std/pale): 危険度予測モデルの学習用地図画像そのもの
- 国土数値情報(国土交通省): 行政区域(N03)・鉄道駅(N02、最寄り駅距離)
- PLATEAU(3D都市モデル): 23区内交差点の見通しをAIの説明根拠として活用
- 道路種別・信号機・横断歩道等の位置情報を集計統計として活用

## 周辺アーキテクチャ

- フロントエンド: HTML/CSS/Vanilla JS、Leaflet.js。ひらがな中心のやさしいUI
- AI対話バックエンド: Claude API(Tool Use)が危険度スコア・事故データ・地点情報をツールとして呼び出し、実データに基づく説明を生成
- インフラ: Cloudflare Workers + Containers(本ハッカソンのCloudflare特典を活用)
- プライバシー: 自宅・学校の位置情報はその場で処理するのみでサーバー保存しない設計
